# Masha Grand Prix ↗

Персональное интерактивное поздравление: белая Toyota Carina ED Маши, заезд за подарками, праздничный подход в зале и финал с пожеланиями. Для телефона и компьютера. Без подписей отправителя, регистрации, аналитики, внешних шрифтов и сетевых зависимостей во время работы.

## Запуск через Docker

```sh
docker compose up -d --build
```

Открыть **http://localhost:8080**. Проверка: `docker compose ps`, журнал: `docker compose logs -f`. Остановить: `docker compose down`.

Порт по умолчанию доступен только на локальном компьютере. Для другого порта: `PORT=8090 docker compose up -d --build`.

## Размещение на сервере с HTTPS

В проект включён Caddy в Docker: он принимает запросы на 80/443, получает и продлевает сертификат, перенаправляет HTTP на HTTPS и передаёт запросы приложению по внутренней сети Docker (`birthday:8080`). Включено сжатие HTML, CSS и JavaScript. Само приложение остаётся на `127.0.0.1:8080`.

1. Направить DNS-запись A домена на публичный IPv4 сервера. Если есть AAAA, она должна указывать на рабочий IPv6 этого же сервера.
2. Порты 80 и 443 должны быть доступны извне и свободны для Caddy. Если на сервере уже работает nginx/Caddy/Traefik, добавить домен в существующий прокси с upstream `127.0.0.1:8080` вместо запуска второго прокси на тех же портах.
3. Скопировать проект на сервер и создать `.env`:

```sh
cp .env.example .env
```

В `.env.example` домен намеренно пустой. В своём `.env` укажи `DOMAIN=твой-домен` без `https://` и без пути. Реальный `.env` не хранится в Git и не включается в архив. Затем:

```sh
docker compose -f compose.yaml -f compose.https.yaml up -d --build
```

Открыть `https://ВАШ_ДОМЕН` — порт в ссылке указывать не нужно. При первом запуске получение сертификата может занять некоторое время.

Проверка и журналы:

```sh
docker compose -f compose.yaml -f compose.https.yaml ps
docker compose -f compose.yaml -f compose.https.yaml logs --tail=100 proxy
```

Остановка:

```sh
docker compose -f compose.yaml -f compose.https.yaml down
```

Сертификаты хранятся в постоянном Docker volume `caddy_data`, настройки Caddy — в `caddy_config`. Обычный `down` их сохраняет; `down -v` удалит их вместе с сертификатами.

Caddy: [автоматический HTTPS](https://caddyserver.com/docs/automatic-https), [reverse proxy](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy).

### Если DNS управляется через Cloudflare

Для первого запуска создать A-запись нужного поддомена с IP сервера и статусом **DNS only** (серое облако). После запуска Caddy и получения публичного сертификата проверить `https://ВАШ_ДОМЕН`. Затем можно включить **Proxied** (оранжевое облако) и режим **SSL/TLS → Full (strict)**. У Cloudflare также должен быть активен edge-сертификат для этого имени.

Порты 80 и 443 на origin-сервере нужны и при включённом Cloudflare.

Cloudflare: [Full (strict)](https://developers.cloudflare.com/ssl/origin-configuration/ssl-modes/full-strict/), [статус проксирования](https://developers.cloudflare.com/dns/proxy-status/).

### Прямой доступ с телефона в одной Wi-Fi-сети

Без HTTPS-прокси:

```sh
BIND_ADDRESS=0.0.0.0 PORT=8080 docker compose up -d --build
```

Затем открыть `http://IP_КОМПЬЮТЕРА:8080`.

## Локальный запуск без Docker

Python 3.12+, сторонние пакеты не нужны. В `requirements.txt` явно зафиксировано отсутствие внешних зависимостей; Dockerfile не запускает `pip install` или установку системных пакетов. Python и Caddy закреплены по SHA-256 digest, чтобы сборка использовала те же образы, которые были проверены.

Запуск:

```sh
python3 main.py
```

В PyCharm можно просто запустить `main.py`. По умолчанию сервер слушает `0.0.0.0:8080`; для доступа только с компьютера: `HOST=127.0.0.1 python3 main.py`.

## Что внутри

- Toyota Carina ED на прозрачном фоне, воссозданная по фотографиям машины Маши, с тремя цветами кузова; изображение создано специально для проекта встроенным image_gen. Промпт — в ASSETS.md.
- Заезд на 30 секунд: ← / →, A / D (и русская раскладка), экранные кнопки, касания и свайпы. Пауза останавливает время; при уходе с вкладки игра встаёт на паузу.
- Жим на 8 повторений: попасть в зелёную зону, либо включить спокойный режим без тайминга. Кнопка и пробел работают с клавиатуры.
- Любой этап можно открыть сразу или пропустить. Подарок доступен при любом результате.
- У заезда и зала — разные награды и поздравления. Четыре варианта общего финала учитывают пройденные этапы. Три раскрывающихся пожелания; постоянное конфетти на всём сайте. Скачиваний нет.
- Звук синтезируется Web Audio и включается только по кнопке. По умолчанию выключен.
- Прогресс, рекорд и цвет сохраняются в `localStorage` только на текущем устройстве. Если хранилище недоступно, всё работает без сохранения.
- Учтены клавиатурная навигация, системное уменьшение анимации и узкие экраны.

## Где менять тексты и дизайн

`static/index.html` — главная, дата и ник. `static/app.js` — навигация и пожелания. `static/celebrations.mjs` — награды и варианты финала. `static/effects.js` — непрерывное конфетти, которое ставится на паузу в фоновой вкладке. `static/style.css` — оформление. `static/games.js` — игры; правила вынесены в `static/model.mjs`. `static/sound.js` — звуки.

## Проверки

```sh
python3 -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

Контейнер работает от отдельного пользователя, с read-only файловой системой, без дополнительных capabilities. `/healthz` используется встроенным healthcheck. Python-сервер раздаёт только папку `static`, содержимое проекта по HTTP недоступно. Для небольшого поздравления этого достаточно; TLS и доменное имя обслуживает включённый Caddy или существующий reverse proxy сервера.
